# About Nous

**Nous** is an AI-powered super agent that researches, codes, and creates.

## Key Features

- **Deep Research**: Automated search and analysis
- **Code Execution**: Sandboxed code environments
- **Memory**: Persistent per-user memory
- **Skills**: Extensible skill system
- **Multi-Agent**: Orchestrated sub-agents
