# 文件与协作看板交互验收

本记录补充同日的主会话队列、多层委派和插件控制。沿用 Nous 主题，统一右侧工作区的交互规则；不声明像素级复制 DSH 桌面。

## 交互更新

- 子 Agent、文件、Swarm 移动端共用 WorkspaceSideSheet，提供焦点约束、Escape 关闭及入口焦点恢复。移动端文件面板不再同时挂载隐藏的桌面预览。
- Swarm 保留实际 team_id，关闭后可从页头重开；查看持久团队不再取决于输入框当前是否勾选 Swarm。关闭执行面板不再自动弹出另一个看板。桌面支持键盘与指针调整宽度。
- Swarm SSE 使用与其他业务 API 一致的同源代理，移除浏览器侧硬编码 127.0.0.1 网关地址。连接故障显示错误及显式重试，团队结束与重连状态分开；成员状态提供可访问的中文标签。
- HTML 预览在隔离 iframe 中执行脚本，不能访问父页面；实际上传的 HTML 已验证脚本可运行且父页面访问被阻断。
- 文件读取检查实际 HTTP 状态，读取失败显示错误与重试，不再将 404 / 503 JSON 当作文件内容渲染。关闭预览会取消未完成的内容请求。上传文件不在结果清单时仍显示正确文件名。
- 设置分类在移动端使用紧凑横向导航，保留内容区域；实际验证了移动端插件启用、停用与仅保留一个弹窗。
- 补上移动端导航入口，将设置弹窗移出侧栏抽屉，避免关闭导航后设置弹窗一起卸载；插件、工具、技能等设置可从移动端实际进入。
- 文件无文字提交能实际上传并入队。等待计划审核时保留停止按钮；运行终结或切换时清除旧审核卡，不阻塞独立排队任务。
