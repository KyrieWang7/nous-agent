# 前端 DSH 会话工作区与验收

本轮在 `develop` 接入上一轮已验证的 Go 后端接口，沿用 Nous 的主题和现有 Next.js 页面。新增交互全部读取实际 API，不使用静态任务、模拟进度或浏览器定时器推导终态。没有修改后端，也没有提交、推送或部署远端。

## 对齐内容

参考本地 DSH `39163dd30f703a79079e2d2446545cff3c453738`：

- `packages/client/ui-subagent/src/client/SubagentHeaderLineage.tsx`：主会话与子会话的层级导航。
- `packages/client/ui-subagent/src/client/sidebar-chat/index.tsx`：在侧边栏保留子会话视图，通过稳定地址恢复选中的会话。
- `packages/client/ui-sidebar-right`、`ui-plan`：将子会话和执行计划组织到右侧工作区。

实现由当前 React 应用承载，不引入 DSH 的 Cordis、Electron 或插件 UI 运行时。具体行为：

1. 右侧执行面板提供“子 Agent / 执行计划”页签。会话树从后端加载，包含父子关系、注册类型和实际状态；不依赖当前输入框选择的模式，刷新后仍可查看历史孩子。
2. 主对话任务卡可打开对应持久子会话。URL 的 `subagent` 参数保存选择，刷新后恢复；不同 thread 的查询缓存、输入草稿和控制请求彼此隔离。
3. 子会话显示已持久化的输入、Agent 回复、工具调用与结果，以及上下文来源、用量、结束原因、部分结果和协调错误。
4. 运行中可以发送补充消息、等待结果和停止子 Agent。等待不锁住停止按钮；等待超时只结束等待，不将孩子标记为失败。停止请求返回后继续读取实际状态，等待后端排空资源。
5. 补充消息显示后端的 pending / consumed 状态，分别呈现为“待接纳 / 已接纳”。发送的消息 ID 在浏览器会话中保留，失败重试复用同一个 ID。
6. 空闲的直接子会话可以续接。接受的 run 直接接入现有 SSE 消费器，不再 POST 第二次运行。接受响应丢失时，通过已有运行查询恢复连接，不自动重发命令。主会话忙碌或非直接子级时，明确限制续接。
7. 主会话“停止”改为实际后端取消请求，保留事件连接直到结算；页面导航只断开订阅。运行中按回车保留草稿，不隐式取消当前运行。主会话未实现自动排队，因此没有显示虚假的排队入口。
8. 计划页读取真实待办、待审核计划和历史 `exit_plan_mode` 参数。计划确认继续使用已有审核入口；计划模式标记来自实际运行事件，不自行改变后端权限。
9. 移动端使用带焦点约束的抽屉，支持 Escape 关闭与焦点恢复；桌面支持鼠标拖动和键盘调整面板宽度。新增文案提供中英文。

## 修复的状态问题

- 原消息分组会把 task 结果挂到之前的普通工具组，导致刷新后任务卡长期显示运行中。现在 task 与其结果保持同组，后续工具进入新的处理组，并有回归测试。
- 移除消息渲染过程中更新 SubtasksProvider 的做法，历史卡片直接从已有转录构建。
- 历史任务卡保留该次调用的终态和输出；后续续接不会把旧卡片的结果覆盖成最新子会话回复。取消、执行超时与等待超时也分开显示。缺少终态事实时显示“暂无终态记录”。
- HTTP 409 保留草稿并刷新状态，不重试 POST。初次读取失败时显示错误和重试入口，不显示虚构的空会话或可用控制项。
- 流连接增加归属检查，旧线程的迟到响应不会覆盖新线程状态。

## 接口与代码边界

`frontend/src/core/subagents` 封装持久会话 DTO、HTTP 客户端、查询键和树形目录；`components/workspace/subagent` 负责展示与交互。请求经过现有 `/api/agent` 代理进入 Go `/api/v1`，没有新增浏览器直接访问数据库或 Redis 的路径，也没有新增依赖。

原来仅由流事件驱动的独立子任务列表组件已删除。既有 Swarm 和文件面板保留，通过工作区入口使用；本轮没有把它们宣称为 DSH 全量桌面功能，也没有新增后端尚不支持的插件管理或根会话排队控件。

- Playwright 使用真实本地服务验证桌面 1440×1000、移动端 390×844、中英文界面，没有页面 JavaScript 异常。

真实模型和实际持久化验证：

| 路径 | 验证结果 |
| --- | --- |
| 从任务卡打开子会话，再续接 | 实际 run 成功，读回此前保存的随机标记 |
| 运行中发送补充消息 | 返回 202，界面与数据库均显示 pending |
| 等待期间停止孩子 | 停止按钮可用，实际孩子和父 run 结算为 cancelled |
| 显式续接消费 pending | 记录变为 consumed，模型读回只存在于补充消息中的随机验证码 |
| 主会话运行中按回车 | 不发送新 run，不取消当前 run，草稿保留 |
| 主会话停止 | 实际 POST runs/cancel，父级及孩子均取消并排空 |
| 刷新、移动端关闭后重开 | 选择、历史及本会话草稿恢复，抽屉焦点正确，无横向溢出 |

另在浏览器验收脚本中注入 409、503 和“后端接受后丢失响应”三种故障，验证草稿保留、重试恢复、禁用无数据时的控制，以及命令只 POST 一次。故障注入没有进入业务代码。
